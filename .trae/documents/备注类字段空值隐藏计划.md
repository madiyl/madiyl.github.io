# 备注类字段空值隐藏计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 统一所有模块中“备注类字段”的浏览态行为，当字段未填写时默认不展示，减少“待填写”占位噪音。

**Architecture:** 保持当前各阶段组件的数据结构不变，只在浏览态渲染层增加条件判断。范围按已确认口径限定为“备注类字段”，即：`备注`、`说明`、`选购理由` 这类补充说明信息；不修改施工流程中 `实际进度`、`关键细节`、`风险 / 待办` 这类核心信息区。

**Tech Stack:** React 18、TypeScript、Tailwind CSS、现有 `EditableField` 与各阶段组件

---

## Summary

本轮优化目标很聚焦：

1. 浏览态下，如果备注类字段为空，不再显示字段标题和“待填写”占位。
2. 编辑态下，备注类字段仍然保留，方便继续录入。
3. 已经做过空值隐藏的主材模块保持一致，其它模块补齐同样策略。

## Proposed Changes

### 1. 统一备注类字段的浏览态隐藏条件

**文件：**
- 修改：[`src/components/stages/AppliancesStage.tsx`](file:///Users/bytedance/madiyl.github.io/src/components/stages/AppliancesStage.tsx)
- 修改：[`src/components/stages/PeopleIntroStage.tsx`](file:///Users/bytedance/madiyl.github.io/src/components/stages/PeopleIntroStage.tsx)
- 修改：[`src/components/stages/DesignStage.tsx`](file:///Users/bytedance/madiyl.github.io/src/components/stages/DesignStage.tsx)
- 修改：[`src/components/stages/SoftFurnishingStage.tsx`](file:///Users/bytedance/madiyl.github.io/src/components/stages/SoftFurnishingStage.tsx)

**变更内容：**

对这些字段统一改成条件渲染：

- 电器模块：`item.note`
- 人员介绍模块：`person.note`
- 设计阶段：`asset.note`
- 软装模块：`item.reason`

统一口径：
- 编辑态：始终显示输入框
- 浏览态：只有当对应字符串 `trim()` 后非空时才显示

建议采用与主材模块一致的判断方式：

```tsx
{editMode || item.note.trim() ? (
  <EditableField
    label="备注"
    value={item.note}
    ...
  />
) : null}
```

对于不同字段替换成对应变量名即可，例如：
- `person.note.trim()`
- `asset.note.trim()`
- `item.reason.trim()`

## Assumptions & Decisions

1. “备注类字段”本轮只覆盖：
   - `备注`
   - `说明`
   - `选购理由`
2. 施工流程里的 `实际进度 / 关键细节 / 风险待办` 不属于备注类字段，不做隐藏。
3. 主材模块现有逻辑已满足需求，本轮只补齐其它模块。
4. 不在 `EditableField` 做全局隐藏，而是在各阶段组件局部控制，避免误伤。
