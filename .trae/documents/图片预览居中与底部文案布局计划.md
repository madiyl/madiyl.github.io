# 图片预览居中与底部文案布局计划

## Summary

当前图片预览灯箱已经支持：

- 主图查看
- 上一张 / 下一张
- 右侧缩略图切换
- 标题与说明展示

但现有布局是：

- 主图与缩略图并列
- 标题和说明单独放在主图下方卡片里

你要的效果是参考截图进行重排：

1. 图片在预览区内成为绝对视觉中心
2. 标题和副标题放到底部
3. 保持整体简洁、偏作品展示，而不是信息卡片感

本次计划会以现有 `ImageLightbox` 为基础，改造成更接近你截图里的预览样式，并让设计阶段、软装阶段共享同一套表现。

## Assumptions & Decisions

基于当前实现和你提供的参考图，本次计划锁定以下决策：

1. **复用现有 `ImageLightbox`**
   - 不新建另一套预览组件
   - 直接重构现有灯箱布局

2. **主图保持居中展示**
   - 主图区域的视觉中心优先级最高
   - 使用 `object-contain` 保证整图不被裁切
   - 图片容器采用居中对齐，不让文案打断主视觉

3. **标题 / 副标题放到底部**
   - 不再作为主图下方独立信息卡块
   - 改为灯箱底部的信息带或底部信息区
   - 语义保持：
     - `alt` = 标题
     - `caption` = 副标题

4. **保留右侧缩略图栏**
   - 参考图里已有右侧缩略图
   - 当前交互也已支持，保留能减少额外改动

5. **保留左右切换与关闭按钮**
   - 仅调整视觉位置和样式，不删除现有能力

6. **影响范围为所有使用 `ImageLightbox` 的场景**
   - 设计阶段
   - 软装阶段

#### 做什么

#### 为什么

- 你要的是更偏作品展示的沉浸式预览

#### 怎么做

这样可以让图片始终在视觉中心，而不是被下方文案卡片拉低重心。

## Data Flow / Interaction Flow

### 点击图片

1. 用户点击设计图或软装图
2. 当前阶段把图片数组和当前索引传给 `ImageLightbox`
3. 灯箱打开后：
   - 主图在中间区域居中展示
   - 标题与副标题显示在底部
   - 右侧显示缩略图列表

### 切换图片

1. 用户点击右侧缩略图，或点击上一张 / 下一张
2. `activeIndex` 更新
3. 主图切换
4. 底部标题 / 副标题随当前图片同步更新

## Edge Cases & Failure Modes

- **没有副标题**
  - 底部仅显示标题
  - 不保留空白说明区域

- **标题较长**
  - 控制字号和行高，避免把底部区域挤得过高

- **竖图 / 横图比例差异大**
  - 仍使用 `object-contain`
  - 主图居中，不做裁切

- **只有一张图**
  - 右侧缩略图栏可继续显示单图
  - 左右翻页按钮仍可隐藏或禁用

- **移动端**
  - 右侧缩略图栏可回落到底部横向区
  - 但标题/副标题仍然保持在主图底部之后
