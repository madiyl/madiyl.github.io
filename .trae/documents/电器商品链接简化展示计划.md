# 电器商品链接简化展示计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 简化电器模块中的商品链接展示，浏览态不再显示链接详情，只保留点击跳转按钮。

**Architecture:** 保持现有电器数据结构和编辑逻辑不变，仅调整 `AppliancesStage` 的浏览态链接 UI。编辑态仍保留完整 URL 输入，浏览态把当前“商品链接 + 域名前缀”展示改成单一跳转按钮，避免卡片里出现链接详情文本。

**Tech Stack:** React 18、TypeScript、Tailwind CSS、现有 `AppliancesStage` 组件

---

## Summary

本轮改动只做一件事：

1. 电器模块浏览态不再展示商品链接的详情文本（当前是域名前缀），只保留一个用于跳转的按钮。

## Current State Analysis

### 当前实现

- [`src/components/stages/AppliancesStage.tsx`](file:///Users/bytedance/madiyl.github.io/src/components/stages/AppliancesStage.tsx)
  - 编辑态已经支持录入 `productUrl`。
  - 浏览态如果存在 `productUrl`，会渲染一个链接块：
    - 左侧文字：`商品链接`
    - 右侧详情：`getLinkDisplayPrefix(item.productUrl)`

- [`src/utils/url.ts`](file:///Users/bytedance/madiyl.github.io/src/utils/url.ts)
  - 当前专门负责把完整 URL 裁成域名前缀，如 `jd.com`。

### 与当前需求的差异

- 用户这次明确要求：
  - “不需要展示商品链接的详情”
  - “保留下面的点击跳转按钮就行”

**结论：**
- 需要保留 `productUrl` 数据和跳转能力。
- 只需要移除浏览态的链接详情文本，不需要再展示域名前缀。

## Proposed Changes

### 1. 简化电器模块的浏览态商品链接区

**文件：**
- 修改：[`src/components/stages/AppliancesStage.tsx`](file:///Users/bytedance/madiyl.github.io/src/components/stages/AppliancesStage.tsx)

**变更内容：**
- 保留编辑态的 `商品链接` 输入框，不改数据录入方式。
- 浏览态中，如果 `item.productUrl` 存在：
  - 不再显示 `getLinkDisplayPrefix(item.productUrl)` 这类详情文本
  - 改成单一按钮式展示，例如：
    - 左侧主文案：`点击跳转`
    - 或按钮整体只显示：`查看商品`
- 按钮继续保留：
  - `href={item.productUrl}`
  - `target="_blank"`
  - `rel="noreferrer"`

**原因：**
- 用户只想保留动作入口，不想在卡片里看到链接来源或短链详情。

### 2. 清理不再需要的 URL 展示工具引用

**文件：**
- 修改：[`src/components/stages/AppliancesStage.tsx`](file:///Users/bytedance/madiyl.github.io/src/components/stages/AppliancesStage.tsx)
- 仅检查：[`src/utils/url.ts`](file:///Users/bytedance/madiyl.github.io/src/utils/url.ts)

**变更内容：**
- 如果 `AppliancesStage` 不再使用 `getLinkDisplayPrefix`，删除对应 import。
- `src/utils/url.ts` 是否保留取决于当前项目中是否还有其它调用点：
  - 若无其它引用，可后续清理
  - 若仍有其它引用，则仅移除当前组件中的使用

**原因：**
- 避免留下无用 import 或无意义的展示逻辑。

## Assumptions & Decisions

1. 这次只改浏览态显示，不改编辑态输入方式。
2. 商品链接仍然保留为完整 URL，点击后继续新开页面跳转。
3. “不展示详情”理解为不再显示域名前缀或短链文本，只保留动作按钮。
4. 本轮不扩展到其它模块的附件/链接样式，范围仅限电器商品链接。
